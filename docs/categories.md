# Supported Game Categories

Games can be tagged with one or more of the following categories.

## Match-3
Tile-matching puzzle games focused on pattern recognition and combo mechanics.  
Reference implementation:
<a href="https://fgl.com/tags/match-3/">FGL Match-3 category</a>

## Puzzle
Logic-based and brain-training games designed for thoughtful play.  
Reference implementation:
<a href="https://fgl.com/tags/puzzle/">FGL Puzzle category</a>

## Arcade
Skill-based arcade games emphasizing timing, reaction speed, and mastery.  
Reference implementation:
<a href="https://fgl.com/tags/arcade/">FGL Arcade category</a>
